# دليل المعلم: إنشاء الأسئلة والاختبارات والموافقة عليها

---

## 🧭 نظرة عامة على المسار

```
معلم → مجموعات أسئلة ← أسئلة ← اختبار ← موافقة المشرف ← طالب → تصحيح
```

---

## 1️⃣ إنشاء مجموعة أسئلة (Question Group)

المجموعة هي **مجلد** يجمع أسئلة متعلقة بموضوع معين (مثل: "الباب الأول - التفاضل").

**الخطوات:**

1. سجل الدخول بحساب **معلم**
2. اذهب إلى الرابط:  
   `/teacher/question-banks`
3. ستظهر صفحة بها:
   - **حقل نصي** لإدخال اسم المجموعة
   - **زر** لإضافة المجموعة
   - **جدول** بالمجموعات الموجودة
4. اكتب اسم المجموعة (مثال: "اختبار الشهر الأول - الجبر")
5. اضغط **حفظ**
6. ستظهر المجموعة في الجدول

---

## 2️⃣ إنشاء أسئلة داخل المجموعة

بعد إنشاء المجموعة، تظهر قائمة بالأسئلة (فارغة حالياً).

**الخطوات:**

1. من صفحة المجموعات `/teacher/question-banks`،
   اضغط على **اسم المجموعة** أو زر **عرض**
2. ستظهر صفحة المجموعة وفيها:
   - جدول بالأسئلة الموجودة
   - زر **إضافة سؤال**
3. اضغط على **إضافة سؤال**
4. ستفتح صفحة إنشاء السؤال وفيها:

### الحقول المطلوبة:

| الحقل | الشرح |
|-------|-------|
| **مجموعة الأسئلة** | يتم تحديدها تلقائياً |
| **التصنيف** | اختر التصنيف الرئيسي (رياضيات - علوم - لغة عربية ...) |
| **التصنيف الفرعي** | اختر التصنيف الفرعي إن وجد |
| **نوع السؤال** | اختر نوع السؤال (انظر الجدول أدناه) |
| **السؤال** | اكتب نص السؤال (يدعم التحرير الغني والرموز الرياضية) |
| **الدرجة** | حدد درجة السؤال (مثال: 5) |
| **الشرح** | (اختياري) شرح الإجابة يظهر للطالب بعد الإجابة |
| **صورة** | (اختياري) صورة توضيحية للسؤال |
| **خلط الخيارات** | (لاختيار من متعدد) لخلط ترتيب الخيارات عشوائياً |

### أنواع الأسئلة المتاحة:

| النوع | الكود | الوصف |
|-------|-------|-------|
| اختيار من متعدد | M | عدة خيارات وواحد أو أكثر صحيح |
| صح/خطأ | T | عبارة صحيحة أو خاطئة |
| ملء الفراغات | F | كلمة أو عبارة ناقصة يملؤها الطالب |
| إجابة قصيرة | S | إجابة مكتوبة بجملة قصيرة |
| إجابة طويلة | L | إجابة مفصلة (تحتاج تصحيح يدوي) |
| ترتيب | O | ترتيب عناصر في تسلسل صحيح |
| كلمة ناقصة | C | اختيار الكلمة المناسبة من قائمة |
| توصيل | X | توصيل العناصر في العمود الأيمن بالأيسر |
| لغز | P | تركيب وتوصيل متقدم |

### 📐 كتابة الرموز الرياضية:

عند كتابة السؤال في المحرر:
- اضغط على أيقونة **∑** (الموجودة في الزاوية السفلى اليسرى)
- ستظهر لوحة الرموز الرياضية
- اكتب المعادلة في حقل النص العلوي (مثل: `x^2 + y^2 = z^2`)
- شاهد المعاينة المباشرة
- اضغط **إدراج المعادلة**
- أو اختر من القوالب الجاهزة (كسور - تكاملات - جذور ...)

### للأسئلة من نوع "اختيار من متعدد":

5. بعد ملء الحقول الأساسية، انتقل لأسفل إلى **الخيارات**
6. اكتب الخيار الأول واضغط **إضافة خيار**
7. كرر لإضافة الخيارات (على الأقل 2)
8. اختر الخيار الصحيح بوضع علامة ✅ في دائرة الاختيار
9. يمكنك إضافة **صورة** لكل خيار إن أردت

10. اضغط **حفظ** لإضافة السؤال
11. كرر الخطوات لإضافة المزيد من الأسئلة

---

## 3️⃣ إنشاء اختبار (Quiz)

بعد إنشاء الأسئلة، تحتاج إلى إنشاء اختبار وربطه بمقرر دراسي.

**الخطوات:**

1. من القائمة الجانبية، اذهب إلى **الاختبارات عبر الإنترنت**
2. اضغط على **إضافة اختبار جديد**
3. املأ الحقول:

| الحقل | الشرح |
|-------|-------|
| **العنوان** | اسم الاختبار (مثال: اختبار الجبر - الشهر الأول) |
| **التعليمات** | تعليمات تظهر للطالب قبل بدء الاختبار |
| **التصنيف** | التصنيف الذي ينتمي له الاختبار |
| **المقرر الدراسي** | **اختر المقرر الذي تريد إضافة الاختبار له** |
| **مجموعة الأسئلة** | اختر مجموعة الأسئلة التي أنشأتها سابقاً |
| **نسبة النجاح** | النسبة المئوية المطلوبة للنجاح (مثال: 50%) |
| **الوقت (بالدقائق)** | المدة الزمنية للاختبار |
| **عدد المحاولات** | كم مرة يمكن للطالب إعادة الاختبار |
| **عرض الإجابات** | هل تظهر الإجابات الصحيحة بعد الانتهاء |
| **خلط الأسئلة** | ترتيب عشوائي للأسئلة |

4. اضغط **حفظ**

⚠️ **ملاحظة:** الاختبار الذي ينشئه المعلم يكون بحالة **قيد الانتظار (Pending)** ولن يظهر للطلاب حتى يوافق عليه المشرف.

---

## 4️⃣ إضافة أسئلة إلى الاختبار

1. من قائمة الاختبارات، اضغط على **إضافة أسئلة** بجانب الاختبار
2. ستظهر صفحة بها جميع الأسئلة المتاحة
3. اختر الأسئلة التي تريد إضافتها بواسطة مربعات الاختيار
4. اضغط **حفظ الأسئلة**
5. يمكنك تعديل درجة كل سؤال بشكل منفصل

⚠️ بعد تعديل الأسئلة، يعود الاختبار إلى حالة **قيد الانتظار** ويحتاج موافقة جديدة.

---

## 5️⃣ موافقة المشرف (Admin Approval)

الاختبارات التي ينشئها المعلم **لن تظهر للطلاب** حتى يوافق عليها المشرف.

**المشرف (Admin):**

1. سجل الدخول بحساب **مشرف**
2. اذهب إلى **الاختبارات عبر الإنترنت**
3. ستجد الاختبارات بحالة:
   - 🟡 **قيد الانتظار (Pending)** ← تحتاج الموافقة
   - 🟢 **منشور (Published)** ← تمت الموافقة ونشط للطلاب
4. للاختبارات قيد الانتظار، اضغط على زر **نشر الآن (Publish Now)**
5. سيصبح الاختبار منشوراً ويظهر للطلاب

**ملاحظات:**
- المشرف فقط هو من يمكنه نشر الاختبارات
- لا يوجد زر "رفض" — الاختبار يبقى قيد الانتظار لحين النشر
- يمكن للمشرف التواصل مع المعلم لتعديل الاختبار قبل النشر

---

## 6️⃣ الطالب يؤدي الاختبار

**للطلاب:**

1. سجل الدخول بحساب **طالب**
2. اذهب إلى المقرر الدراسي الذي يحتوي الاختبار
3. ستجد الاختبار في قائمة محتوى المقرر
4. اضغط على **بدء الاختبار**
5. اقرأ التعليمات واضغط **بدء**
6. أجب عن الأسئلة واحداً تلو الآخر:
   - **اختيار من متعدد**: اختر الإجابة الصحيحة
   - **صح/خطأ**: اختر صح أو خطأ
   - **إجابة قصيرة/طويلة**: اكتب الإجابة في الحقل النصي
7. يمكنك التنقل بين الأسئلة
8. عند الانتهاء، اضغط **إنهاء الاختبار**
9. ستظهر النتيجة فوراً للأسئلة الموضوعية (اختيار من متعدد، صح/خطأ)

---

## 7️⃣ تصحيح الأسئلة المقالية (Manual Marking)

للأسئلة التي تحتاج تصحيحاً يدوياً (إجابة قصيرة، إجابة طويلة):

**المعلم أو المشرف:**

1. اذهب إلى قائمة الاختبارات
2. اضغط على **سجل الدرجات** أو **التصحيح**
3. اختر الطالب الذي تريد تصحيح إجابته
4. ستظهر إجابات الطالب مع الأسئلة
5. للأسئلة الموضوعية: الدرجة محسوبة تلقائياً
6. للأسئلة المقالية: اكتب الدرجة التي تراها مناسبة
7. اضغط **حفظ التصحيح**
8. بعد التصحيح، يتم احتساب النتيجة النهائية (نجاح/رسوب)

## 📋 ملخص مسار العمل الكامل

```
المعلم:
  1. ينشئ مجموعة أسئلة  ←  /teacher/question-banks
  2. يضيف أسئلة للمجموعة  ←  /teacher/question-banks/{id}/questions/create
  3. ينشئ اختباراً  ←  /quiz/set-quiz
  4. يربط الأسئلة بالاختبار  ←  /quiz/manage-online-exam-question/{id}

المشرف:
  5. يوافق على الاختبار وينشره  ←  /quiz/online-exam-publish/{id}

الطالب:
  6. يؤدي الاختبار  ←  /quizStart/{course_id}/{quiz_id}/{slug}
  7. يشاهد النتيجة  ←  /quizResult/{quiz_test_id}

المعلم/المشرف:
  8. يصحح الأسئلة المقالية  ←  /quiz/online-exam-marking/{exam_id}/{s_id}
```
