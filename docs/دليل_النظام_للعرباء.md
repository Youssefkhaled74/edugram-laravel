# دليل نظام LMS (نظام إدارة التعلم) - InfixLMS / EduGram

## 🧭 نظرة عامة على النظام

هذا النظام هو منصة تعليمية متكاملة (Learning Management System) تسمح بـ:
- إنشاء حسابات **مدرس (Instructor)** و **طالب (Student)** و **مشرف (Admin)**
- إنشاء **كورسات (Courses)** تحتوي على دروس وفيديوهات
- إنشاء **اختبارات (Quizzes/Exams)** داخل الكورسات
- تسجيل الطلاب في الكورسات وحل الاختبارات
- إصدار **شهادات (Certificates)** بعد إتمام الكورسات

---

## 🔐 أنواع المستخدمين والأدوار

| الدور | الوصف |
|-------|-------|
| **Super Admin** | مدير النظام - صلاحية كاملة (role_id = 1) |
| **Instructor (مدرس)** | يقوم بإنشاء الكورسات والاختبارات (role_id = 2) |
| **Student (طالب)** | يسجل في الكورسات ويحل الاختبارات (role_id = 3) |
| **Staff** | موظف إداري (role_id = 4) |

## 📋 شرح دورة الاستخدام الكاملة (Testing Cycle)

### المرحلة 1: تسجيل حساب مدرس جديد
```
1. افتح الرابط: http://127.0.0.1:8000/register
2. املأ البيانات:
   - الاسم
   - البريد الإلكتروني
   - كلمة السر
3. بعد التسجيل، سيتم إنشاء الحساب بدور "طالب" افتراضيًا
4. لتغيير الدور إلى "مدرس":
   - سجل دخول بحساب الأدمن: admin@infixlms.com / 12345678
   - اذهب إلى لوحة التحكم ثم إدارة المستخدمين
   - ابحث عن الحساب الجديد وغيّر دوره إلى Instructor
```

**ملاحظة:** يمكنك أيضًا استخدام الحساب الجاهز `teacher@infixlms.com` مباشرة بدلًا من إنشاء حساب جديد.

### المرحلة 2: إنشاء كورس جديد (بواسطة المدرس)
```
1. سجل دخول بحساب المدرس (teacher@infixlms.com)
2. اذهب إلى: http://127.0.0.1:8000/admin/course/new/course
   أو من لوحة التحكم: اختر "Courses" ← "Add New"
3. املأ بيانات الكورس:
   - عنوان الكورس (Title)
   - الفئة (Category)
   - السعر (Price) - يمكن تركه 0 لكورس مجاني
   - وصف الكورس (About/Description)
   - الصورة المصغرة (Thumbnail Image)
   - المستوى (Level)
4. اضغط "Save"
5. انتظر حتى يتم حفظ الكورس
6. ✅ تم إنشاء الكورس بنجاح
```

### المرحلة 3: إضافة دروس وفصول للكورس
```
1. من صفحة الكورس بعد الحفظ، اختر "Chapters"
2. أضف فصل (Chapter):
   - اسم الفصل (مثلاً: "Chapter 1: Introduction")
   - اضغط Save
3. أضف درس (Lesson) داخل الفصل:
   - اختر الفصل → "Add Lesson"
   - اختر نوع المحتوى (فيديو - PDF - نص)
   - املأ البيانات المطلوبة
   - اضغط Save
```

### المرحلة 4: إنشاء اختبار (Quiz) داخل الكورس
```
1. سجل دخول بحساب المدرس
2. اذهب إلى قسم Quiz من لوحة التحكم:
   http://127.0.0.1:8000/quiz/set-quiz
3. اضغط "Add New Quiz" وأدخل:
   - اسم الاختبار (Quiz Title)
   - التعليمات (Instructions)
   - الوقت المسموح (Time)
   - درجة النجاح (Percentage)
4. اضغط Save
```

#### إضافة أسئلة للاختبار:
```
1. بجانب الاختبار، اختر "Questions" أو "Manage Question"
2. اضغط "Add Question"
3. اختر نوع السؤال:
   - Multiple Choice (اختيار من متعدد)
   - True/False (صح/خطأ)
   - Fill in the Blanks (املأ الفراغ)
4. اكتب السؤال والإجابات وختر الإجابة الصحيحة
5. حدد الدرجة (Marks)
6. أضف الأسئلة التي تريدها
7. ✅ تم إنشاء الاختبار
```

#### ربط الاختبار بالكورس:
```
1. من صفحة تعديل الكورس، اذهب إلى "Lessons"
2. يمكن إضافة درس جديد واختيار نوعه "Quiz"
3. أو من إعدادات الكورس، اختر الاختبار المناسب
```

### المرحلة 5: الاشتراك في الكورس (بواسطة الطالب)
```
1. افتح متصفح آخر أو سجل خروج من حساب المدرس
2. سجل دخول بحساب الطالب: student@infixlms.com / 12345678
3. اذهب إلى صفحة الكورسات: http://127.0.0.1:8000/courses
4. ابحث عن الكورس الذي أنشأه المدرس
5. اضغط على الكورس لعرض التفاصيل
6. اضغط "Enroll Now" أو "Add to Cart" ← "Checkout"
7. اختر طريقة الدفع (أو اختر Free إذا كان مجانيًا)
8. ✅ تم الاشتراك في الكورس بنجاح
```

### المرحلة 6: مشاهدة دروس الكورس
```
1. من لوحة تحكم الطالب:
   http://127.0.0.1:8000/my-courses
2. اختر الكورس المسجل فيه
3. شاهد الدروس بالفصول المختلفة
4. يمكنك وضع علامة "مكتمل" (Complete) لكل درس
```

### المرحلة 7: حل الاختبار (بواسطة الطالب)
```
1. من داخل الكورس، اذهب إلى قسم الاختبارات
2. اختر الاختبار المطلوب
3. اضغط "Start Quiz" لبدء الاختبار
4. أجب على الأسئلة واحدًا تلو الآخر
5. اضغط "Submit" بعد الانتهاء
6. ✅ ستظهر النتيجة فورًا (درجتك ودرجة النجاح)
```

### المرحلة 8: مراجعة النتائج (بواسطة المدرس)
```
1. سجل دخول بحساب المدرس
2. اذهب إلى: http://127.0.0.1:8000/quiz/quiz-result
3. شاهد نتائج جميع الطلاب في الاختبارات
4. يمكنك تصحيح الإجابات المقالية إن وجدت
```

## 🧪 ملخص دورة الاختبار الكاملة

```
إنشاء حساب مدرس
       ↓
  إنشاء كورس جديد
       ↓
  إضافة دروس وفصول
       ↓
  إنشاء اختبار (Quiz)
       ↓
  إضافة أسئلة للاختبار
       ↓
  تسجيل طالب في الكورس
       ↓
  مشاهدة الدروس
       ↓
  حل الاختبار
       ↓
  عرض النتيجة
```
