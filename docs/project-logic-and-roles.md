# لمحة سريعة عن المشروع وطريقة عمله

- منصة LMS تعمل كنظام SaaS لبيع الدورات الرقمية وإدارة المحتوى التعليمي.
- مصادر الإيراد: مبيعات دورات، اشتراكات، بوابات دفع، وعمولات على أرباح المدرّسين.
- الجهات الفاعلة: Super admin (تحكّم كامل)، Instructors (ينشئون الدورات)، Students (يشترون ويتعلّمون)، Staff (إدارة).
- التدفق الرئيسي: إنشاء دورة → شراء/اشتراك → استهلاك المحتوى → تتبّع التقدّم → دفع أرباح.
- التحكم بالوصول عبر جداول `roles`/`permissions` وmiddleware `RoutePermissionCheck`.
- النظام يدعم multi-tenant والكاش للواجهات؛ تغيّر الصلاحيات يتطلّب مسح الكاش.
- نقاط تشغيلية مهمة: حماية المفاتيح، مراقبة المدفوعات، وضبط صلاحيات دقيقة لكل دور.
